# The Avena — Cloud Kitchen Desk (Frontend Demo)

## Run
1. Extract this ZIP and open the folder in VS Code.
2. Open `index.html` with Live Server, or double-click it.
3. Click **Sign in** or open `login.html` directly. Choose User or Admin.
4. To manage kitchen records, sign in with the demo admin credentials below.

## Included
- Homepage based on the supplied The Avena logo
- High-contrast neon-garden palette: vivid greens, lime, mint, citrus gold and warm cream
- Preloader, animated ticker, realistic generated food photography in WebP (<100 KB), animated hero, glowing loader, scroll-reveal effects and motion accents
- Responsive mobile navigation
- Light/dark theme switch, saved in local browser storage
- Testimonial cards with previous/next controls (copy is labelled as sample/demo content)
- User/admin login and signup UI
- Admin dashboard for stock, raw-material purchases, suppliers, quantity, unit price, expenses and categories
- Purchase logs update inventory quantities; low-stock alerts; search/filter history; CSV export
- Custom 404 page with Back and Home navigation
- Logo and hero food WebP images each optimized below 100 KB

## Important
This is a frontend prototype only. Records are stored in this browser using localStorage; there is no backend, database, secure authentication, sync between devices, or automatic backup. Frontend-only role checks can be bypassed. Use sample data, not confidential financial or password information.
